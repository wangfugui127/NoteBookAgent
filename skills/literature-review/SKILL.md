# Literature Review

1. 先明确研究问题、范围与年份。
2. 先检索 Notebook，再按需搜索外部论文。
3. 区分 Notebook 原文证据、外部摘要线索和模型推断。
4. 对关键结论附上可定位到文档版本、页码和 Chunk 的引用。
5. 证据不足时明确说明缺口，不把摘要伪装成全文证据。
